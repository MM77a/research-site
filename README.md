## Publish a paper note

Upload a Markdown file such as `repa.md` into `research-blog/papers/`. Jekyll will create the article and update the paper index. See [publishing instructions](research-blog/PUBLISHING.md).

This repository does **not** contain the original CS180 project files; those remain in the separate `MM77a.github.io` repository to preserve previously submitted course URLs.
